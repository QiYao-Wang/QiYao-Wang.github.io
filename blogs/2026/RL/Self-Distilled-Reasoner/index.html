Self-Distilled Reasoner：用答案条件化教师监督学生自己的轨迹

📅 2026年10月11日 · Qiyao Wang · AI 辅助阅读 #Paper · #RL · #Distillation

Self-Distilled Reasoner 研究的不是“让模型相信自己”，而是让同一个模型在获得参考解后，为看不到参考解的自己提供更密集的训练信号。关键差别在于信息条件：学生沿自己的轨迹生成，教师在同一个前缀上额外读取正确解；在 Qwen3-1.7B 的三个数学基准上，论文报告的平均 Avg@12 从 37.1 提升到 43.4，但这不是无监督学习，也不是每一道题都超越 GRPO。

六个关键结论

  • 问题：SFT 学的是参考解的前缀，推理时却遇到自己的前缀；仅有最终正确性奖励的 RL 又可能在整组回答同对或同错时失去区分信号。
  • 机制：对学生实际走过的前缀，让拥有参考解的教师输出全词表分布，再做逐 token 蒸馏；主要实验采用前向 KL。
  • 证据：1.7B、4B、8B 的跨任务平均分均超过同表的 SFT 和 GRPO；8B 的 HMMT25 则是 GRPO 46.7 高于 OPSD 45.8。
  • 实践：每题一次短 rollout 能获得密集反馈；参考答案既可以引导教师，不一定必须作为学生直接模仿的全文。
  • 代价：需要正确参考解、额外教师前向和全词表 logits；较少的生成 token 不能直接等同于较少的端到端 GPU 时间。
  • 开放问题：教师能否识别学生已经出错的推理，并提供有效纠正，而不是仅把已知答案合理化？

同一模型为什么能成为教师

令问题为 \(x\)，参考解为 \(y^\star\)，学生已生成的前缀为 \(\hat y_{<t}\)。学生分布是 \(p_S(\cdot\mid x,\hat y_{<t})\)，教师分布则是 \(p_T(\cdot\mid x,y^\star,\hat y_{<t})\)。教师的优势来自额外上下文，而非一定更多的参数。这个设定与答案条件化的 rationalization 有关：已知目标答案，可以帮助模型判断接下来应该走向哪里。

重要的实现细节：论文概念上讨论同模型不同上下文，实际实验将教师冻结为初始策略，学生随后继续更新。因此不能把结果解释成“教师与学生永远共享当前权重”的在线自改进。模型规模相同，也不意味着训练信息相同。

蒸馏的对象不是参考轨迹，而是学生状态

从学生采样 \(\hat y\sim p_S(\cdot\mid x)\)，在每个访问到的状态上计算：

\[\mathcal L_{\mathrm{FKL}}=\mathbb E_{x,\hat y}\!\left[\frac1{|\hat y|}\sum_t\sum_{v\in\mathcal V}p_T(v\mid x,y^\star,\hat y_{<t})\log\frac{p_T(v\mid x,y^\star,\hat y_{<t})}{p_S(v\mid x,\hat y_{<t})}\right].\]

教师分布停止梯度，采样出的前缀作为训练数据处理。这里的 on-policy 是指状态由学生产生，不意味着必须对整个采样过程求导。前向 KL 的 soft targets 同时告诉学生哪些 token 应被增加、哪些应被减少；这与只给最终答案一个二元奖励不同，也与照抄参考解不同。

论文还对逐词表的散度贡献做 clipping，以限制少数强烈的风格信号。它不是 PPO 的概率比 clipping，也不是“所有 KL 小于某个阈值”的硬约束。截断会改变优化信号：稳定性收益以失去部分大误差纠正信号为代价，阈值应被当成建模选择，而非纯数值技巧。

全词表前向 KL 不等于采样 token 的反向 KL

另一种实现只对已采到的 token 计算 \(A_t=\log p_T(\hat y_t)-\log p_S(\hat y_t)\)，将停止梯度的 \(A_t\) 用作策略梯度系数。它更接近反向 KL 的采样估计，和全词表前向 KL 并非同一损失。以 Qwen3-1.7B、AIME25 Avg@12 为例，前向 KL 在 50/100 步为 43.9/41.1，反向 KL 为 37.5/35.0，JSD（权重 0.5）为 36.9/39.0。这支持当前配置选择前向 KL，不能证明所有蒸馏任务都应如此。

消融揭示什么，又没有揭示什么

Qwen3-4B 的 full-logit / sampled-token 对比采用 2,048 token 的训练生成预算，AIME25 Pass@8 为 84.1/82.1，HMMT25 为 60.0/57.3。这个消融支持软分布监督更有效，但它采用的 Pass@8 不能与主表 Avg@12 直接比较。

教师开启 thinking、学生关闭 thinking 的组合，在作者的 token 类别诊断中提供较强数学信号；这些类别由关键词划分，而且只在少量题目上统计，不是精确的“数学知识”测量。论文认为早期 token 可能是关键分叉点，短 rollout 因此有效：这是合理解释，仍需位置消融来验证。

SFT 的下降也可能与简短参考解和推理风格的冲突有关。一个更强的控制是对长度、格式和可读性匹配后的 SFT 再比较，而不是将当前下降概括成“SFT 无法训练推理”。教师已知正确答案，却未必知道正确的中间步骤；错误前缀、超出其理解范围的难题和参考解噪声，都可能产生自信但不可靠的分布监督。

最值得做的后续实验

固定初始模型、参考解和总 GPU 小时，对比冻结教师、周期刷新教师与强外部教师；同时把学生前缀按“正确、可恢复错误、不可恢复错误”分层，测量教师下一步建议的可验证正确率。这样才能分清收益来自额外答案信息、教师能力，还是更贴合学生状态的监督。检查点只在独立验证集上选择，并报告多随机种子与实际 token、教师 prefill、logit 通信成本。

结论与系列定位

OPSD 把专家信息转化为学生当前状态上的软监督，解决的是“在哪里教”和“教得多细”。E2S 则试图学习适合学生且正确的完整轨迹分布，两者不能仅因都使用答案条件化而混为同一种算法。
