Retaining by Doing：遗忘差异究竟来自目标，还是训练数据

📅 2026年10月11日 · Qiyao Wang · AI 辅助阅读 #Paper · #RL · #Forgetting

Retaining by Doing 要解释的不是“RL 比 SFT 好”，而是更具体的现象：在后训练中，为什么对新任务有相近收益的模型，会丢掉不同数量的旧能力？Howard Chen 等人跨 Llama / Qwen、指令遵循 / 知识 / 算术任务比较后，把关键因素指向训练数据是否来自正在更新的策略。论文同时保留反例：只有起始学生的自生成数据并不够，RL 也并非免疫于遗忘。

六个核心判断

  • 问题：专家 SFT 和静态 Self-SFT 都可能在获取新技能时损伤旧能力。
  • 机制：on-policy 更新更容易沿已有可达模式改善，而不是被外部示范拉向远处的模式。
  • 证据：REINFORCE 与 GRPO 都保持较低遗忘，移除 KL 正则也往往如此；优势估计和正则不是唯一解释。
  • 实践：每 epoch 刷新自生成数据的 Iterative-SFT，可以获得部分 on-policy 保留收益，不必每步重采样。
  • 边界：Self-SFT 会随学生更新变成 off-policy；当新模式离起点太远，RL 也可能忘。
  • 开放问题：应该多久刷新数据，才足以控制分布陈旧度？答案需要计算—收益联合评价。

一、必须同时衡量 gain 和 drop

论文把新任务准确率的变化记为 gain，把其他任务平均准确率的下降记为 drop：

\[ \Delta_g=\mathcal A(\pi_T,\mathcal T)-\mathcal A(\pi_0,\mathcal T),\qquad \Delta_d=\frac1M\sum_j\big[\mathcal A(\pi_0,\mathcal T'_j)-\mathcal A(\pi_T,\mathcal T'_j)\big]. \]

gain 越高越好，drop 越低越好；负 drop 表示非目标任务均值反而上升。百分制准确率相减得到的是百分点变化，不是相对改进率。均值还可能掩盖某一旧任务特别严重的下降，因此实际部署需要逐项检查。

目标任务是 IFEval、MMLU、Countdown。每次学习其中一项，检查其余项，并加入 MATH、WildJailbreak 和 WildGuardTest 作为旧能力与安全性代理。数据划分分别为 IFEval 13,000 / 1,972，MMLU 12,000 / 2,042，Countdown 10,000 / 1,000 的训练 / 测试样本。

二、不要把 Self-SFT 误叫作持续 on-policy

学生包括 Llama-3.2-1B-Instruct、Llama-3.1-8B-Instruct、Qwen2.5-1.5B-Instruct、Qwen2.5-7B-Instruct。专家 SFT 使用 Llama-3.3-70B-Instruct 的有效回答；Self-SFT 从起始学生为每题生成五个回答，保留正确者；GRPO 则用当前策略的 rollout 和二元奖励更新。

方法回答来源数据何时刷新？学生更新后的状态
Expert SFT外部 70B 教师训练前与学生可能持续不匹配
Self-SFT起始学生训练前起点接近，之后逐渐陈旧
Iterative-SFT每 epoch 开始时的学生每 epoch近似 on-policy
GRPO当前学生每个更新周期更接近完全 on-policy

“由我自己生成”是模型来源，而“on-policy”还涉及检查点与时间。一批数据即使来自学生，一旦学生连续更新，它也不再严格来自当前分布。这正是 Offline 与 Online E2S 的分界之一。

三、mode-seeking 为什么可能反而保留更多？

SFT 相当于最小化示范分布到学生的前向 KL；带参考策略 KL 正则的 RL 则可写成对奖励倾斜目标的反向 KL：

\[ \pi^*(y\mid x)=\frac{\pi_0(y\mid x)e^{r(x,y)/\beta}}{Z(x)},\qquad J(\pi)=-\beta D_{\mathrm{KL}}(\pi\|\pi^*)+\beta\log Z(x). \]

这两种 KL 的参照是目标策略，不要与衡量微调前后变化的 \(D_{\mathrm{KL}}(\pi_0\|\pi)\) 混为一谈。通常说前向 KL mode-covering、反向 KL mode-seeking，也不能直接推出谁更忘。

论文用高斯混合给出直观反例。如果学生只能表示一个模式，把它挪向新模式必然伤到旧模式，此时前向 KL 的保留反而稍好：相同 0.9 新模式 gain，旧模式 drop 为 0.64 对 0.70。允许学生有两个模式后，反向 KL 可以主要调整已经存在的新模式，旧模式保持较完整，而前向 KL 的外部样本可能牵动整体混合结构。

这不是 LLM 内部真的存在可逐个命名的高斯模式，而是强调起始能力结构决定更新如何传播。附录增加新旧模式距离后，RL 也开始遗忘，所以“当前策略采样”不是万能屏障。

REINFORCE 在目标任务优化上有时远弱于 GRPO，却仍出现低 drop，说明 GRPO 特定的优势估计不是保留优势的必要条件。但它们的 gain 并不处处匹配；较少学习也可能较少改变，因此该表要与其余匹配权衡和消融一起看。

另一项消融去除 KL 正则后，大多数模型 / 数据仍有类似保留优势；例外包括 Llama 的 IFEval。这里排除的是“显式 KL 正则解释了全部优势”，不是说 KL 正则在任何任务都没有用。

五、近似 on-policy 到什么程度就够了？

Iterative-SFT 在每个 epoch 开始时重新生成并筛选有效回答，再进行该轮 SFT。论文观察它往往能接近或超过静态 SFT 的目标表现，同时明显减少遗忘。另一个用 RL 过程中收集的轨迹做 SFT 的实验，也获得较好的保留。

这使“每步采样”与“完全静态数据”之间出现了实际可用的连续谱。不过，RL 日志中的回答只是对生成它们的历史检查点 on-policy；把它们重新交给起始模型训练时，不能声称全过程严格 on-policy。

一种合理的实践方向是同时追踪样本年龄和策略变化：当当前模型对旧数据的概率明显改变时刷新，而不是机械地按固定时间刷新。这是本文提出的方案，不是论文已经验证的算法。

六、KL 是信号，不是遗忘证书

附录用 100 个评价样本估计微调前后的前向 KL，跨模型、方法和任务与 drop 的 Pearson 相关为 0.52。GRPO 总体同时具有较低 KL 和较低 drop，但 SFT 与 Self-SFT 之间并不总是单调。

具体地，在 Llama-3.2-1B 的 MMLU 实验中，Self-SFT 的 KL 为 39.3、drop 为 34.6；专家 SFT 的 KL 更高（48.4），drop 却更低（28.9）。这些 KL 数值是论文对应估计流程的结果，不能跨不同长度和分布随意横向比较，更不能据此设一个全局阈值。

与 RL’s Razor 合读，可以得到更稳妥的判断：分布变化值得监测，但输入分布、KL 方向、序列长度、模型参数化和旧任务重叠会影响代理强度。该论文的高斯分析提供直觉，不等同于对非凸 Transformer 的完整证明。

结语：保留优势来自哪里，必须拆开测

这项工作把采样来源、采样时间、KL 正则和优势估计拆开，避免把多个共同变化统称为“RL 的魔力”。下一步最有价值的实验，是对不同刷新间隔进行等生成 token、等更新 token 的对照，同时报告目标 gain、逐项旧任务 drop、样本陈旧度与方差。

对 E2S 而言，它解释了为什么适配一次的数据未必足够：学生改变后，数据生成分布可能也应跟着改变。但刷新本身的成本与收益，仍需测量而非凭名称判断。
