E2S Finetuning：学习一个贴近学生的正确轨迹采样器

📅 2026年10月11日 · Qiyao Wang · AI 辅助阅读 #ResearchBlog · #RL · #Sampling

专家能给出正确答案，不等于专家的表达方式就是学生最容易学会的训练数据。Haoqiang（Murray）Kang 的研究博客提出 E2S Finetuning：先学习一个受专家信息约束、又尽量贴近学生分布的采样器，再用它生成监督微调（SFT）数据。在博客公布的 Qwen2.5-3B 数学实验中，Offline / Online 的四项数学平均准确率为 55.5% / 59.4%；这是完整训练流程的比较，并不是等总计算量的速度结论。本文以论文阅读的方式重建这个想法，区分理论目标、实际训练算法和实验能够支持的判断。

来源说明：E2S 的直接来源是作者的研究博客，不是本文已核实的独立 arXiv 论文。它承接 Finetuning with Sampling 的受约束采样目标，并借助 GFlowNet 学习可复用采样器。下文凡称“E2S 实验”，均指作者博客公布的项目结果；相关论文的结果会单独标注。

先记住六件事

  • 问题：普通 SFT 不仅传递专家知识，也要求学生模仿专家的具体轨迹；这两件事并不等价，后者可能带来额外分布偏移。
  • 机制：专家定义“哪些回答可以接受”，学生定义这些回答之间的相对概率；GFlowNet 负责学习从这个条件分布中采样。
  • 证据：同一数学评价套件上，MCMC + SFT、E2S-Offline、E2S-Online 的 Math avg. 分别为 53.4%、55.5%、59.4%，但基线引用自另一项研究，未做等总计算量对照。
  • 实践：当正确答案已经有了、学生却难以自行采到正确轨迹时，可以改造训练数据的生成分布，而不必首先改造 SFT 损失。
  • 代价：采样器训练、参考模型打分、有效性验证和被拒绝的输出都要付费；“摊销搜索”不自动意味着总成本更低。
  • 开放问题：有限采样器究竟保留了多少正确解法？Online 的收益来自分布跟踪、更多训练，还是更好的覆盖？需要预算匹配和模式覆盖实验区分。

一、为什么“给正确示范”仍可能不好学？

设问题为 \(x\)，专家回答分布为 \(q_{\mathrm{data}}(y\mid x)\)，学生为 \(p_\theta(y\mid x)\)。SFT 对专家回答做最大似然训练：

\[ \mathcal L_{\mathrm{SFT}} =\mathbb E_{y\sim q_{\mathrm{data}}}[-\log p_\theta(y\mid x)] =H(q_{\mathrm{data}})+D_{\mathrm{KL}}(q_{\mathrm{data}}\|p_\theta). \]

固定数据下，第一项不随学生参数变化。也就是说，SFT 要求学生向专家的数据分布靠近，而不仅是让“最终答案正确”。若专家喜欢很长的证明、特殊的记号或学生几乎不会产生的中间步骤，这些表达习惯也一起进入监督信号。

在 token 层面，这个差异更具体：训练时 \(p_\theta(y_t\mid x,y_{<t})\) 接收到的是专家写出的前缀；推理时接收到的却是学生自己写出的前缀。示范越偏离学生，训练与实际执行之间的上下文差异就可能越大。

但不要把这条 KL 恒等式直接读成“偏移必然导致遗忘”。学习新能力本来就需要改变分布；不同方向的变化也可能影响不同能力。RL’s Razor 与 Retaining by Doing 为这一动机提供分析和实验，结论仍依赖模型、任务及其假设。

二、两条路线：移动监督，还是移动数据？

把“学生和专家不在同一个分布上”拆成不同干预位置。
路线谁产生训练轨迹？专家信息如何进入？主要困难
RL / GRPO学生答案或奖励评估学生轨迹全错组可能没有相对优势；正确轨迹稀少
On-policy distillation学生教师在学生前缀上给出下一 token 分布教师打分成本及教师—学生能力差异
MCMC + SFT从专家轨迹出发反复改写验证改写是否保留专家信息每个样本重新运行搜索链
E2S + SFT学到的条件采样器专家轨迹作为采样器输入，验证输出学习近似采样器及保持分布覆盖

前两条路线把监督移到学生已经走出的轨迹上；后两条路线把示范改造成学生更容易吸收的轨迹。E2S 与 MCMC 的目标接近，关键区别是是否把搜索经验保存在共享参数中。MCMC 为每一道题重新搜索，E2S 则希望一题上的训练能改善其他题上的采样。

还需要区分参考论文中的理想 MCMC 与实际基线：Finetuning with Sampling 的附录为了省去反向提议打分，使用“高似然候选优先替换”的近似，生成数据正确率也不是 100%。因此两种方法共享理论动机，不等于实验中都精确采到了同一个受约束分布。

三、真正的目标不是“最可能的正确答案”

令 \(\tau\) 为专家轨迹，\(C_\tau\) 为满足其语义约束的回答集合。数学题可以要求最终答案正确；知识任务则可能要求保留关键事实，后者更依赖评估器。固定学生检查点的分布记为 \(p_{\mathrm{ref}}(y\mid x)\)。希望找到：

\[ q^*=\arg\min_{\operatorname{supp}(q)\subseteq C_\tau} D_{\mathrm{KL}}(q\|p_{\mathrm{ref}}). \]

在 \(Z_\tau=\sum_{y\in C_\tau}p_{\mathrm{ref}}(y\mid x)>0\) 时，解为：

\[ q^*(y\mid x,\tau)= \frac{p_{\mathrm{ref}}(y\mid x)\mathbf 1[y\in C_\tau]}{Z_\tau}. \]

这来自 Finetuning with Sampling 的信息投影。对任何满足约束、且 KL 有限的 \(q\)，有：

\[ D_{\mathrm{KL}}(q\|p_{\mathrm{ref}}) =D_{\mathrm{KL}}(q\|q^*)-\log Z_\tau. \]

第二项是常数，第一项在 \(q=q^*\) 时取最小值。这个推导说明：专家筛选支持集，学生保留支持集内部的偏好。例如，学生原本给两个正确方案分配 6% 和 3% 的概率，受约束分布会把它们变成 \(2/3\) 和 \(1/3\)，而不是只保留概率最高的方案。这里的数值是解释性例子，不是实验结果。

因此，“更 on-policy”要精确理解为受约束的学生分布，并非完全不加条件的原始学生采样。即使匹配完全成功，距离原学生仍有 \(-\log Z_\tau\) 的最小 KL。若正确解极少，所需变化可能依然很大。

这也揭示一个边界：若学生对所有有效答案都给零概率，\(Z_\tau=0\)，该条件分布无法定义。实际语言模型通常给许多 token 序列非零概率，但“非零”不等于计算上容易发现；采样器和专家提示负责跨越的是这个实际困难。

四、用 GFlowNet 学习未知归一化常数的分布

我们可以给某个回答计算 \(R_\tau(y)=p_{\mathrm{ref}}(y\mid x)\mathbf1[y\in C_\tau]\)，却不能穷举所有回答算出 \(Z_\tau\)。GFlowNet 的用途是：学习一条逐步生成策略，让完整结果的概率与给定的非归一化奖励成比例，而不是只寻找最高奖励结果。

对自回归文本，一个完整 token 序列对应一条生成路径，序列概率是各 token 概率的乘积，包含终止 token。有效回答上的 trajectory balance（TB）残差可以写成：

\[ \ell_{\mathrm{TB}}(y)= \big[z_\tau+\log q_\phi(y\mid x,\tau)-\log R_\tau(y)\big]^2. \]

\(\phi\) 是采样器参数，\(z_\tau\) 是归一化常数的对数偏移。若所有有效回答上残差都为零，归一化会要求 \(z_\tau=\log Z_\tau\)。这里“所有”很重要：有限训练组上的拟合不能证明全局覆盖。

把归一化常数变成组内中心化

对同一 \(x,\tau\)，收集 \(K\ge2\) 个有效回答，定义：

\[ a_i=\log q_\phi(y_i\mid x,\tau)-\log p_{\mathrm{ref}}(y_i\mid x), \qquad \bar a=\frac1K\sum_i a_i. \]

固定这些回答，最小化 \(\frac1K\sum_i(z+a_i)^2\) 时有 \(z=-\bar a\)。代入得到：

\[ \mathcal L_{\mathrm{sampler}}=\frac1K\sum_i(a_i-\bar a)^2. \]

这里调节的是概率比的相对失衡：相对组平均偏高的回答被采样器过度表示，偏低的回答则表示不足。它与 GRPO 都使用组内信息，但优化对象不同：GRPO 通常中心化结果奖励，E2S 中心化的是采样器与学生之间的序列 log-probability 差。

固定组内样本时，是否对 \(\bar a\) 停止梯度不改变该平方损失的梯度，因为 \(\sum_i(a_i-\bar a)=0\)。不过，这不意味着可以忽略采样策略的变化：博客算法每次用新采样组做一步更新，把采到的回答视为固定；复用旧 rollout 需要另行处理 off-policy 偏差。

中心化可以消去接受率，不能提高接受率

原始采样器可能生成无效回答。设它的有效输出概率为 \(A_\phi>0\)，则有效回答的条件分布为 \(q_\phi^+(y)=q_\phi(y)/A_\phi\)。改用 \(\log q_\phi^+\) 会给每个 \(a_i\) 减去同一个 \(\log A_\phi\)，所以组内中心化把这项抵消了。

被抵消的是未知常数，不是无效输出的成本。如果采样器只有很低接受率，这个损失本身没有直接要求它消除无效概率质量；正确性检查仍决定哪些样本进入 SFT。实现时应记录原始生成数、接受数、验证成本，而不能只报告保留下来的样本数。

同样，必须使用与实际采样分布一致的完整序列分数。平均 token log-probability、改变温度或 top-p 截断都可能改变目标；不能把它们作为“无害的打分优化”混用。

五、Offline 与 Online：固定学生，还是跟踪学生？

Offline：冻结起始学生 \(\theta_0\)，训练采样器，生成固定数据集 \(D^*\)，最后对学生做 SFT。优点是数据和训练容易分离、重现；缺点是学生更新后，固定数据仍匹配旧学生。

Online：每轮先冻结当前学生，适配采样器并生成新数据；再关闭采样器，对学生做 SFT；下一轮重新适配更新后的学生。它解决的是目标分布随学生变化的问题，而不是把 SFT 换成新的 RL 损失。

实现上，作者使用学生骨干加 LoRA 适配器。启用适配器时，采样器看见 \(x,\tau\)；禁用适配器时，学生只看 \(x\)。采样器训练冻结骨干，学生 SFT 禁用适配器。因此训练时的专家信息不是测试时学生额外拥有的信息。Online 改动骨干后，同一组 LoRA 参数所定义的采样分布也会受影响，继续适配是算法的一部分。

七、多采样的收益，是否就是多样性的收益？

1× 到 4× 提高 2.2 个百分点，说明不增加专家题目也能从额外生成回答中获益。一种合理的解读是，专家信息可以通过多种学生友好的表达进入训练；但数据量与 SFT 计算也同时增加，因此这不是对“解法多样性”的单独测量。

我会优先补一个对照：同样 4× 的 token 预算，一组重复同一回答，另一组使用四次采样；再比较不同推理簇的覆盖率、正确率和迁移。如果复制控制也获得同样收益，“多样性”就不是必要解释；如果多样样本在等预算下仍更强，因果故事才更有说服力。

八、阅读时要守住的四条边界

  1. 语义约束不是无误的神谕。最终答案验证可能放过错误推理，LLM 事实评估器可能漏掉关键内容；此时采样器忠实匹配的只是评估器允许的集合。
  2. 分布目标不等于训练结果。正确的目标具有多个模式，有限采样器仍可能只覆盖容易到达的模式。低组内损失不能证明没有模式坍缩。
  3. 低偏移不是永远应当坚持的目标。若原学生恰好偏好错误结构，保留其偏好可能限制新技能学习；需要检查约束能否纠正实质错误，而不是只过滤答案。
  4. 摊销优势需要足够多的后续采样。应把适配器训练、学生打分、生成、拒绝和验证统一换算成 token / GPU 时间，并报告生成数据被多少次复用。

最有判别力的后续实验，应同时控制总训练预算和有效样本数，比较专家 SFT、MCMC + SFT、Offline 和 Online，再测接受率、序列概率差、推理模式覆盖和逐项保留。这比继续增加一个准确率均值更能回答“为什么有效”。

九、怎么读这条研究线？

这些工作不是同一种算法的不同名字。可以按“分布偏移的原因 → 学习目标 → 如何采样 → 如何实现”来读：

  • 为什么遗忘：RL’s Razor、Retaining by Doing。
  • 原来的训练路线：DeepSeekMath / GRPO、Self-Distilled Reasoner、UFT；另读 Thinking Machines 的 OPD 博客。
  • 把数据变得可学习：Finetuning with Sampling。
  • 从最优奖励转向匹配分布：Flow of Reasoning、GFlowVLM、FlowRL、GFlowRL；概念背景见 Bengio 的 GFlowNet 博客。
  • 参数共享如何落地：LoRA。

结语：先定义该教的分布，再选择学习算法

E2S 最值得带走的不是“GFlowNet 又赢了一次”，而是把知识内容与传授形式分开：专家负责确定不能丢掉的信息，学生分布负责确定可以怎样表达，采样器负责把这个要求变成训练数据。它让“数据生成”成为模型适配的一部分；现有结果值得跟进，但效率、覆盖与广泛保留还需要更严格的证据。
