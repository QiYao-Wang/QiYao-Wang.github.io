DeepSeekMath：从数学数据到 GRPO 的完整学习链路

📅 2026年10月11日 · Qiyao Wang · AI 辅助阅读 #Paper · #RL · #GRPO

DeepSeekMath 经常被简化成 GRPO 的出处，但其成绩来自一条完整链路：筛选数学预训练数据、在代码模型上继续训练、监督微调，再做强化学习。真正值得理解的是 GRPO 如何用同题多次回答替代 critic，以及论文为什么认为 RL 更多是在重排已有正确答案的概率，而不是已经证明创造了全新能力。

六个关键结论

  • 问题：数学能力既受预训练覆盖限制，也受正确轨迹的采样概率限制；后训练算法不能脱离基座讨论。
  • 机制：GRPO 通过同一问题的一组奖励构造相对优势，移除单独训练的价值网络，保留概率比 clipping 与参考模型约束。
  • 证据：7B Instruct 到 RL，MATH 无工具 Top1 从 46.8% 到 51.7%，GSM8K 从 82.9% 到 88.2%。
  • 实践：省去 critic 不等于省去 rollout；组大小和组内奖励差异决定信号质量与采样成本。
  • 代价：终点奖励难以定位中间错误；整组同对或同错时，相对优势缺少有效差异。
  • 开放问题：准确率增加究竟是正确轨迹更常出现，还是覆盖了原本不会解决的新问题？

先有数学分布，后有策略优化

作者从 Common Crawl 筛选数学网页，以种子语料训练分类器、识别高质量站点、补充人工规则并迭代；最终数学语料约 120B token。DeepSeek-Coder-Base-v1.5 7B 是起点，继续训练总量约 500B token，除了数学还有代码与自然语言数据。因此 120B 数学 token 不是完整训练量，也不是 RL 的数据规模。

数据管线进行基准去污染，但其效果仍依赖检测策略；代码预训练有助数学推理、arXiv 语料在作者的设置中收益有限，都是条件化实验发现，不是“代码永远优于论文”的普遍规律。后续 SFT 与 RL 是在这一基座上继续改善分布。

从 critic 到组相对优势

同题 \(x\) 从旧策略采样 \(G\) 个回答 \(y_i\)，获得奖励 \(r_i\)，终点监督下每个 token 共用 \(\hat A_i=(r_i-\bar r)/(\operatorname{std}(r)+\varepsilon)\)。这里的微小 \(\varepsilon\) 是实际处理零方差所需的数值保护；原文展示的概念公式不含这一项。

令 token 概率比 \(\rho_{i,t}=\pi_\theta(y_{i,t}\mid x,y_{i,<t})/\pi_{\mathrm{old}}(y_{i,t}\mid x,y_{i,<t})\)。GRPO 最大化组平均的：

\[J=\mathbb E\!\left[\frac1G\sum_i\frac1{|y_i|}\sum_t\left\{\min\big(\rho_{i,t}\hat A_i,\operatorname{clip}(\rho_{i,t},1-\epsilon,1+\epsilon)\hat A_i\big)-\beta D_{\mathrm{KL}}(\pi_\theta\|\pi_{\mathrm{ref}})\right\}\right].\]

相对优势回答“这条比同题其他样本好多少”，clipping 限制对旧数据的激进更新，KL 项约束相对初始参考模型的漂移。两种限制功能不同，不能称为完全替代。论文还讨论过程监督：在步骤边界给更细奖励，优势不再只是全序列相同的终点分数。

原文 KL 采用 \(u-\log u-1\) 的非负采样形式，\(u=\pi_{\mathrm{ref}}/\pi_\theta\)。单个 token 上的这个量是估计项，不是枚举全词表后的精确 KL；讨论无偏性也必须说明采样分布。把所有实现中的 KL 日志当成同一个精确距离，会误导后续遗忘分析。

数据来源与梯度系数的统一视角

原文在较小模型上比较 SFT、离线 RFT、DPO、Online RFT、PPO 和 GRPO。其中 RFT 此处是拒绝采样微调：过滤正确回答后监督学习。SFT 的样本来自人工数据，离线 RFT/DPO 来自固定策略，Online RFT/GRPO 则刷新样本。于是区别不仅是 loss：训练看到哪些状态同样改变。

Online RFT 在后期优于固定数据的 RFT，支持持续刷新样本的价值；GRPO 的正负相对系数与过程监督又带来额外差别。但这些图中方法同时改变数据来源或奖励信号，不能把全部收益单独归于去掉 critic。

Maj@K 增加为何不等于覆盖增加

Pass@K 问 K 次采样中是否至少出现一个正确答案；Maj@K 问多数投票后的答案是否正确。作者温度 0.7 的诊断发现 RL 改善 Maj@K，而 Pass@K 没有同样改善，因而提出概率重排的解释。它提示正确解本已存在但频率不足，却不能证明模型在所有题目、无限采样或所有解题结构上都没有新能力。

二元组奖励还带来信号枯竭：若同组全错，去均值后的奖励全零；全对也一样。提高组大小能增加遇到混合结果的机会，但采样成本同步增长；更密集的监督如 OPSD，或学习正确采样分布如 E2S，正是在处理这个瓶颈。

如何检验“重排”这一解释

固定同一基座与题目，绘制多种 K 下的 Pass@K、Maj@K 和单次准确率；并用可验证的推理步骤聚类统计正确轨迹类型。进一步固定奖励、rollout 总 token 和更新预算，分别改变在线刷新与优势算法。若新方法主要提高频率但没有增加跨题覆盖，应避免写成能力边界已经扩大。

结论

GRPO 是一种去 critic 的组相对策略优化，而 DeepSeekMath 是包括数据、预训练和后训练的系统结果。读懂它，需要同时看信息从哪里来、样本从哪里来，以及目标如何把这些信息变成梯度。
