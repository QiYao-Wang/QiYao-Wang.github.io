SocioVerse → SocioVerse2：从千万用户画像到可检验的动态社会模拟

📅 2026年11月9日 · Qiyao Wang · AI 辅助阅读#Paper · #Agent

让一万个大模型角色同时回答问题，并不自动得到一个可信的社会：人群可能选错，角色可能只是在复述模型的平均偏好，时间与制度也可能没有真正进入决策。SocioVerse 尝试用真实用户痕迹和人口分布校准回答“该让谁来模拟”；SocioVerse2 则把问题推进到“这些人怎样在环境中持续行动，以及研究者怎样修改、回放和检验这个过程”。两篇合起来最值得学习的，是从生成像人的回答，走向构造可检查的社会实验；但不同案例的证据强度差别很大，不能把历史拟合、规则复现和现实因果预测混为一谈。

本文合读 SocioVerse，arXiv:2504.10157v3（2025 年 7 月修订）与 SocioVerse2，arXiv:2609.24911v1（2026 年 9 月技术报告）。依据两版正文、附录和 TeX 源码整理；数值是作者报告的结果，本文没有复跑实验。下文的推导与后续实验建议会单独说明。

先记住六件事

  • 问题：LLM 有知识，不等于其默认回答代表目标人群；模拟社会需要同时对齐人群、信息、行为和测量方式。
  • 机制：一代以用户池和分布采样组织横截面调查；二代把人群、环境和决策函数拆成可替换对象，加入持续状态、环境反馈与实验分支。
  • 证据：一代覆盖选举、新闻反馈和消费调查；二代覆盖七类动态案例，但新闻参照、校准重建、留出预测各自回答不同的问题。
  • 实践：先确定要模拟谁、能看见什么、如何汇总为真实指标，再选择规则、LLM、RL 或混合决策；不是每个代理都必须调用大模型。
  • 代价：大用户池不等于大规模独立证据。属性推断误差、共同模型偏差、长程调用成本与研究者反复调参都会限制结果。
  • 开放问题：最关键的检验，是在冻结设计后，对真正未见的群体、时间和干预保持预测能力；模拟器内部的反事实分支本身不能识别现实因果效应。

一、为什么社会模拟需要比“给模型一个角色”更多的东西？

假设我们想知道，一项住房政策会怎样改变居民搬迁。直接问模型“这项政策有什么影响”，得到的是语言模型对常见论述的综合；让它扮演一位租房家庭，得到的是某个条件下的角色回答。要进一步推断全市的变化，还缺至少三步：这些家庭在真实城市中占多少，他们面对的房租、工作和交通是否不同，以及一个家庭的搬迁如何改变其他家庭下一步看到的环境。

传统 agent-based model（ABM，基于主体的模型）正是处理最后一个问题的工具。研究者规定个体状态、邻接关系和更新规则，让宏观图景从局部互动中产生。Schelling 居住隔离模型的启发在于：不需要每个人都追求高度隔离，局部的邻居偏好也可能形成显著的整体分化。因此，宏观结果不能简单由个体回答的平均值推断，互动与反馈本身就是机制。

规则模型的优点是明确：你知道谁依据什么规则移动，能修改一个参数，观察后果。但规则通常需要研究者提前决定“人如何权衡”，很难覆盖语言表达的政策、复杂生活处境和未预先枚举的反应。LLM 提供了一种更灵活的行为函数：它能同时读取家庭背景、新闻和候选行动，再输出一个决定。代价是函数更难解释，也可能把刻板印象当成个体偏好，把语气流畅当成行为真实性。

这形成两条不能互相替代的研究线。一条追求生成能力：代理能记忆、计划、交谈并产生丰富行为。另一条追求经验对齐：这些行为在什么目标人群、什么测量方式下，与真实观察相符？一段热闹的虚拟社区对话证明系统能运行，却不证明它能预测城市政策。SocioVerse 的主要切入点是第二条；SocioVerse2 再把对齐后的组件接入可持续运行的实验系统。

两篇标题中的 world model 也应按这个语境理解。它们提出的是社会模拟框架及其数据、决策和研究流程，不是训练出一个统一神经网络，已能对所有社会状态进行可靠的下一步预测。二代允许行为函数来自规则、语言模型或强化学习，这恰恰说明贡献重点在组件组织和实验基础设施。

二、SocioVerse：先把“由谁回答”变成一个可操作的问题

四个模块分别约束什么？

一代将模拟拆成社会环境、用户引擎、场景引擎和行为引擎。环境提供社会结构、事件和个体能看到的背景；用户引擎从用户池构造目标人群；场景引擎决定问卷、访谈或互动怎样开展；行为引擎决定代理如何作答或行动。这种拆分的价值是把错误定位：答案不对，可能是行为模型不好，也可能是根本问错了人、给错了信息，或用错了问法。

IPF 为什么有用，又为什么不能恢复未知的真实社会？

选举实验拥有年龄、性别等维度的目标比例，却未必拥有这些属性的完整联合分布。Iterative Proportional Fitting（IPF，迭代比例拟合）从池内的联合频数出发，轮流调整各个维度，使边际分布接近目标。以二维表为例，令 \(x_{ij}\) 表示年龄组 \(i\) 与收入组 \(j\) 的人数，目标行和、列和分别为 \(r_i,c_j\)。标准更新为：

\[ x_{ij}^{(2k+1)}=x_{ij}^{(2k)}\frac{r_i}{\sum_{j'}x_{ij'}^{(2k)}},\qquad x_{ij}^{(2k+2)}=x_{ij}^{(2k+1)}\frac{c_j}{\sum_{i'}x_{i'j}^{(2k+1)}}. \]

第一次把一整行乘以同一个比例，使该年龄组总人数正确；第二次对一整列做同样操作，使收入组总人数正确。列调整可能破坏刚调好的行和，因此需要迭代。这里修正了一代附录 C.1 印刷公式中求和下标没有进入被求和项的问题：行归一化必须遍历列，列归一化必须遍历行。总量需要兼容，分母必须非零；缺失的支持集不能靠除法凭空补出。

下面是本文的假设例子，用于解释限制，并非论文实验。两张表

\[ A=\begin{pmatrix}40&10\\10&40\end{pmatrix},\qquad B=\begin{pmatrix}25&25\\25&25\end{pmatrix} \]

都有相同的行和、列和 50，但一张存在明显相关性，另一张独立。只知道边际，不能判断哪个才是真实联合分布。在所有格子为正的二维情形，IPF 的行列缩放还保持交叉比 \(x_{11}x_{22}/(x_{12}x_{21})\) 不变，因为乘到分子和分母上的行列因子相互抵消。上述两张表的交叉比分别是 16 和 1；目标边际相同，不会让它们自动收敛成同一张表。

因此，IPF 的含义是“在种子分布和支持集约束下对齐已知边际”，不是“从几个比例恢复真实人群”。若某类低收入高学历用户在池中完全缺席，原有零格子经乘法仍是零。补造合成人物可以增加支持，但这引入新的条件分布假设，必须标记来源，不能伪装成观测。

一代附录还坦率报告：选举中对每州使用性别、种族、年龄、意识形态和党派五个维度做 IPF，多数情形没有达到收敛；918 个边际中 888 个误差低于 5%。这比笼统说“已经严格匹配人口分布”更准确。读结果时，应把剩余校准误差纳入解释，而不能把算法名称当作代表性证明。

选举实验的胜者准确率是“多少州判断正确”，RMSE 衡量票份额数值偏差。一个模型可以在优势明显的州取得高胜者准确率，却系统高估某党的支持；也可能在竞争极接近的州只差一点点，但胜者判错。因此要同时看全体州和摇摆州，不能只挑最漂亮的一列。

新闻实验更微妙。作者先找到可能关心科技的用户集合，再以实际讨论 ChatGPT 的用户构造参照集合，限制历史内容的时间，以避免直接把事后帖子放入角色背景。问卷依据态度模型覆盖认知、情感与行为相关维度。但模拟集合与参照集合都由 LLM 代理回答问卷。比较所检验的是：按目标人口特征采样的代理，是否接近由真实讨论者背景构造的代理。它仍有价值，却不能被表述为“预测了真人问卷答案”；两个分布可能共享同一模型的测量偏差。

消费实验对齐官方家庭调查汇总，模拟 16,000 个角色，并比较消费类别结构。附录不是只用一个简单正态收入假设：主体收入使用对数正态，高收入尾部使用 Pareto，经验比例通常为 90% 与 10%。区域平均收入本身不能确定方差、尾部厚度和高收入占比；这些额外选择会影响消费结构。模型答得好坏，混合了收入先验和消费行为函数两层误差。

四、SocioVerse2：从一次调查变成会演化、可修改的实验

第一个循环：行为改变下一步环境

若每个月都重新生成一批角色，再让它们回答当前新闻，那只是很多次独立横截面调查。纵向模拟需要“还是这个人”：他上个月的行动影响本月的状态，其他人的行动也会改变他所处的环境。二代用固定人群 \(P\)、环境 \(E_t\) 和行为函数 \(f\) 表达这个过程：

\[ e_{i,t}=\omega(E_t,p_i),\qquad b_{i,t}=f(p_i,e_{i,t},m_{i,t}),\qquad E_{t+1}=g(E_t,B_t),\quad B_t=\{b_{i,t}\}_{i=1}^{N}. \]

\(p_i\) 是身份及属性，\(\omega\) 决定这个人实际能看到什么，\(m_{i,t}\) 是记忆，\(b_{i,t}\) 是行动，\(g\) 是环境更新。观察函数很重要：城市平均失业率、自己所在工厂的裁员通知、邻居的搬迁和社交平台推送，不能无区别地广播给所有人。二代将物理 / 信息、宏观 / 微观拆成四种观察字段，让暴露差异成为可检查的对象。

执行上，step 0 物化初始状态而不行动；后续每步先注入外生变化，再观察、决策、统一应用行动，最后记录。同步应用使同一步的代理基于同一个时间切片作答，避免仅因遍历顺序不同，让后面的代理提前看见前面代理的结果。这个选择也限制了模型：如果现实中有明确的先后交易、抢占或即时反馈，就要在环境机制或更细时间步中表达，而不是假设同步更新适合一切。

默认记忆保留最近 8 步自身行动，身份 ID 稳定且不复用。稳定 ID 允许比较同一人的变化；有限记忆控制上下文成本，却不意味着它能捕获长期创伤、职业积累或复杂的跨年财务约束。真正需要长期状态的任务，应显式储存资产、债务、健康等变量，不能只期待短文本记忆自动承担全部状态。

行动接口区分类型、负载、理由和来源。例如“打算搬家”不等于“成功搬进一个社区”：环境还要检查预算、空房和容量。二代示例中也区分搬迁意愿与实际执行数量。将意图、执行和后果分层记录，才能知道一项政策是在改变偏好，还是在改变约束。自然语言理由便于审阅，但它是模型生成的说明，不能直接当成忠实的内部决策因果链。

分支必须共享已经发生的历史

设我们在第 \(t^*\) 步改变住房补贴。为了比较同一历史下的两条路径，不能从头重新抽样人群，也不能重新调用模型生成前几步，然后宣称“其他条件不变”。二代保存并回放父运行已经实现的行动，在分叉点重建环境与记忆，随后才调用行为函数生成新行动。这里统一令 \(t^*\) 表示第一个受到干预的步骤：

\[ E'_t=E_t\quad(t<t^*),\qquad E'_{t^*}=\operatorname{op}(E_{t^*}),\qquad \Delta_t=Y(E'_t)-Y(E_t). \]

\(\operatorname{op}\) 是声明的环境操作，\(Y\) 是关心的指标，例如迁居率或价格；之后两条路径各自继续演化。论文有的示例以“最后一个继承步骤”命名 fork，因此写成继承 0–4、从 5 开始干预。实现和阅读时应明确边界，避免把干预前后错开一步。

这个 \(\Delta_t\) 是模型内部的条件对照。它保证“在这套行为与环境机制中，改变该操作后发生什么”，没有保证现实的人也遵循这些机制。即使观察路径拟合得很好，多套不同的机制仍可能在干预后给出相反预测；观测拟合并不能唯一确定反事实。共同 seed 有助于控制随机差异，也不能保证远程 LLM 服务逐位可复现，保存实际输出和运行清单仍然必要。

第二个循环：把研究者的修改也变成实验对象

二代把一个研究定义写作 \(\sigma=(P,E_{0:T},f,\Theta)\)，其中 \(\Theta\) 包含指标、种子和资源配置。研究者提出修改 \(a_k\)，产生新版本 \(\sigma_{k+1}=h(a_k,\sigma_k)\)。这不是训练 LLM 参数的梯度更新，而是人和助手共同迭代研究方案：更换人口校准、修正环境、替换决策器或追加分析。

环境中的未来政策变动可以形成共享历史的分支；改变人群、行为规则或实验定义，通常应成为新版本重新运行。两者的差别直接影响可比性：换掉整个决策模型后跑出的结果，不是对同一个世界施加一次政策干预。版本树保存修改来源，分支树保存共享前史的对照，不能只靠一堆文件名来混用。

标准流程先选字段覆盖更合适的主池，再用共享属性做统计匹配、补充其他字段，最后对目标边际做 IPF；缺失属性可以条件生成，并记录来源。这里有一个很容易忽略的识别问题：若池 A 有收入与教育，池 B 有教育与政策偏好，只按教育拼接，并不能识别“在相同教育下，收入和政策偏好怎样相关”。条件补全可以让表格完整，但完整性不是正确性。若这个未知关系正决定政策响应，拼接假设就会成为结果的主要驱动。

时间安全：数据发生在什么时候，不等于当时已经知道

Event MCP 将宏观、劳动力、金融、住房、新闻及人口调查等来源组织成环境信号。关键不是数据源列表有多长，而是 as-of 查询：在模拟某月某日时，系统只能读取当时已发布的版本。三种时间必须分开：数据描述的参考期、首次发布日期、后来修订日期。一份 1 月经济统计可能 2 月才发布，3 月又修订；让 1 月代理读取最终修订值就是前视泄漏。

二代的做法是在构建阶段抓取和物化时间线，运行阶段从冻结环境包读取，以便重放。这样同一实验不会因为新闻接口第二天改了内容而悄悄换数据。可复现所需的也不只是 seed，而是人口快照、源数据版本、提示、LLM 版本、温度、调用输出、环境机制及指标代码。

不过，输入时间安全只解决显式上下文泄漏。基础模型可能在训练中见过历史选举或经济结果，研究者也可能在多次试验时根据测试期表现改过设计。“提示没有给答案”与“系统从未利用答案”不是同一条件。论文使用知识截止后的窗口是有用补充，但截止日期应落实到准确模型快照和服务配置；不能仅凭一个笼统模型名，宣布完全排除了记忆。

七、规则能被语言模型替代吗？从经典 ABM 到混合舆论

经典 ABM：先测替换行为函数会不会破坏动力学

论文专门做了一个 Schelling 情境探针：在 20×20 网格、400 个主体和相同阈值条件下，标量背景约在第 12 步达到全体满意，加入搬迁成本和耐心等上下文后约在第 18 步达到相同终点。这个探针与上表 30×30 的标准任务是不同配置。它提示终点一致不代表路径一致：若政策关心过渡期成本，仅比较最终满意率会忽略关键差异。

混合舆论：让语言模型负责信息源，让规则负责传播

第二个案例不再坚持人人都用 LLM。300 个核心用户由语言模型驱动，700 个普通用户按意见动力学规则更新；核心用户的帖子通过 mirror coupling 注入普通用户模型。这样复杂语义集中在少量信息源，数量庞大的传播和态度更新由便宜规则完成。该实现没有反向建模普通用户对核心用户的反馈，因此它是有方向性的耦合，不是完整双向社交生态。

八、政策模拟：恢复历史格局与优化制度目标，是不同任务

芝加哥：被扰动的城市，会回到原来的隔离状态吗？

这一实验将 Schelling 从网格搬到 781 个真实街区构成的邻接图。241 类家庭原型由种族、收入、家庭类型和社区类型构成，19,235 个加权代理代表人口；流动率、理想邻里比例与满意度权重参考既有社会学研究。代理先评估满意度，再评估搬迁候选，环境限制迁入容量、各群体搬迁预算与过度聚集。

初始状态不是未来城市，而是 2010 Census 格局中随机挪动 15% 家庭后的扰动状态。研究问题是能否在 15 个抽象步骤内回到既有格局，不能将其写成从未知起点预测多年后的城市。一个常用指标是两群体的不相似指数：

\[ D_{AB}=\frac12\sum_j\left|\frac{A_j}{A}-\frac{B_j}{B}\right|. \]

\(A_j,B_j\) 是街区 \(j\) 中两群体的人数，\(A,B\) 是各群体全市总人数。若每个街区的两群体空间份额一致，指数为 0；完全分离时趋于 1。它衡量空间分布差异，并不直接衡量每个家庭的主观满意度。

九、CCI：从家庭回答拼出宏观信心，增益来自哪里？

消费者信心指数本来就是调查回答的汇总，因此比“直接猜一个宏观数字”更适合自下而上重建。该案例从 SIPP 抽取 5,000 个带权核心家庭，用 GSS 条件分布补充财务满意度、乐观程度与信任等属性，再按人口单元扩展到 250,000 家庭。它不是对 250,000 个独立真实家庭逐一调查，也不等于每个月让 250,000 个 LLM 独立作答。

十二、从两篇论文继续推：怎样知道模拟器究竟错在哪里？

推导一：人口对齐与行为对齐，是两个可相加的误差源

以下是本文的分析，不是论文已证明的结论。先考虑单步、离散群体 \(x\) 的简化情形：真实群体比例为 \(p(x)\)，真实平均反应为 \(\mu(x)\)，模拟器使用 \(q(x)\) 和 \(\widehat\mu(x)\)。真实与模拟总体均值之差可以精确分解为：

\[ \widehat Y-Y =\sum_x[q(x)-p(x)]\mu(x) +\sum_xq(x)[\widehat\mu(x)-\mu(x)]. \]

第一项是人口混合比例错误，第二项是群体内反应错误。一代的分布采样主要针对第一项，行为模型与个性化背景主要针对第二项。即使 IPF 完美匹配所有目标群体，若模型让所有收入层都过度乐观，第二项仍然存在；反过来，单个角色反应很像真人，但抽样过多高收入用户，第一项仍会扭曲总量。

更麻烦的是两项可以相互抵消：错误人群配上错误行为，可能恰好得到正确总体均值。这就是为什么只用一条 CCI 曲线无法验证微观机制。一个有区分力的后续实验，应同时报告真实分组反应与总体结果，并在不同人口混合比例的地区测试同一行为函数。若依靠错误抵消，换一个地区后误差往往重新出现。

在动态场景中，\(p\) 与 \(\mu\) 还受到此前状态和干预影响，上述单步分解不能直接充当全程误差界。它提供的是诊断顺序：先查代表谁，再查组内反应，最后查环境反馈与指标映射，不要把所有偏差都归因于“模型不够大”。

推导二：为什么增加同一种 LLM 代理会很快碰到平台期？

假设 \(N\) 个代理误差同方差为 \(\sigma^2\)，任意两者相关系数均为 \(\rho\)，且这里仅讨论等权平均误差。直接展开方差得到：

\[ \operatorname{Var}(\bar\epsilon) =\frac{\sigma^2}{N}[1+(N-1)\rho],\qquad N_{\mathrm{eff}}=\frac{N}{1+(N-1)\rho}. \]

独立时 \(\rho=0\)，人数增加可以持续降低方差；若共同模型和提示造成正相关，误差存在平台。假设 \(\rho=0.01\)，10,000 个代理的有效样本量仅约 99。这个数值是示意计算，不是对 SocioVerse 相关性的估计；真实权重、不等方差和网络依赖都需要更一般的处理。

它解释了一个重要研究方向：增加多样性不只意味着换名字和年龄，还应检查模型族、提示结构和行为机制是否共享同一种误差。扩展合成人口可以改善覆盖，不能被解释成获得了同样数量的独立真实调查。CCI 的扩展平台期与这一问题相容，但论文没有直接估计 \(\rho\)，所以不能把上述推导宣称为已验证的实验原因。

推导三：共享历史能降低噪声，却不创造现实识别

对第 \(r\) 次独立运行，把同一初始条件下的干预与对照结果记为 \(Y_r(1),Y_r(0)\)，用配对差 \(D_r=Y_r(1)-Y_r(0)\) 估计模型内效应。若各运行对独立：

\[ \operatorname{Var}(\bar D)=\frac1R\left[\operatorname{Var}(Y(1))+\operatorname{Var}(Y(0))-2\operatorname{Cov}(Y(1),Y(0))\right]. \]

若共享前史与随机性让两条路径正相关，配对比较比毫无关联地跑两组实验更稳定；若相关性不为正，降低方差并无保证。无论哪种情形，这都只是蒙特卡洛估计精度，不能减少错误行为规则造成的结构偏差。给一个错误世界反复运行一万次，可能得到非常窄、但离现实很远的置信区间。

因此不确定性单位应是独立运行、情境或合理的时间块，而不是把同一模拟中的几万个相互影响代理全部当作独立重复。药品案例的 1,000 个固定策略 episode、芝加哥的 5 个独立扰动种子、PMI 的单次长时序，各自对应不同的不确定性来源，不能只看“样本数”就排序可信度。

最值得做的后续实验：冻结以后，再让世界改变

如果继续这条研究线，我会优先做一个规模适中但真正盲测的实验，而不是立即把代理数加十倍。先选存在真实分组调查、明确政策时间和可观测行动的场景，冻结人口、环境构造、行为模型、所有校准系数和评价指标，再记录政策出台前的预测。政策之后同时检查总量、分组响应、路径和不确定性，保留所有未命中的预测。

对照应包括简单持久性 / 回归、完全规则、完全 LLM、混合架构，以及固定预算下的模型规模变化。若混合架构已达到同样效果，就没有必要宣称全 LLM 社会必不可少；若简单模型在总量相当，但模拟器能准确预测真实分组异质性，微观建模才展示了独特价值。

还应测试机制错配：保留人口边际但打乱关键联合关系，保留新闻长度但替换为无关事件，冻结人群却换行为模型，再比较哪些结果受影响。这样的实验可以区分真实信息作用、格式作用和模型已有记忆。对研究者编辑循环，则随机安排“允许编辑 / 冻结自动流程”，匹配运行预算并记录全部版本；只展示最后成功的一版，无法估计编辑的价值，也容易掩盖反复查看测试集带来的选择偏差。

在数据治理上，本文只据论文说明其去标识化、访问控制与使用条件，没有独立审计源平台授权。丰富属性组合仍可能带来再识别风险；更重要的是，不应把模型生成的群体偏好当成某类真实人的本质。尤其涉及种族、收入或政治立场时，报告应保留不确定性与校准来源，避免把提示中的假设包装成社会事实。

结语：社会模拟的进步，是让假设变得可以被检验

SocioVerse 将人口选择与个体背景带入 LLM 社会模拟，说明“谁来回答”本身就是方法的一部分；SocioVerse2 则让人群、环境、行为、时间和研究修改进入可追踪的实验结构。两者最有价值的共同点，是把一个貌似自然的生成结果拆成可以分别核验的假设。

现有证据已经展示了跨任务的组织能力、一些有用的统计对齐，以及局部预测增益。但可信的社会模拟不能只靠角色丰富、用户池大或曲线贴合。真正需要跨过的门槛，是在未见的人群、时间与干预下，既预测对总量，也预测对组成这个总量的行为变化，并清楚知道自己何时不可靠。
