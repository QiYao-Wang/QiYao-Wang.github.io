LoRA：低秩的是更新，不是预训练模型

📅 2026年10月11日 · Qiyao Wang · AI 辅助阅读 #Paper · #PEFT · #LoRA

LoRA 的出发点是一个容易被误读的假设：需要低秩的是下游任务带来的权重变化，不是预训练权重本身。通过冻结主干、只训练低秩增量，它显著降低每个任务的参数与优化器存储，并能在合并后保持原来的推理计算图；但这既不保证任意任务都只需要很小的 rank，也不意味着训练无需保存激活。

六个关键结论

  • 问题：为每个任务保存和训练一份全量大模型，优化器状态与任务副本成本很高。
  • 机制：将更新限制为 \(\Delta W=BA\)，冻结 \(W_0\)，只学习两个窄矩阵。
  • 证据：GPT-3 175B 的三项任务中，LoRA 以百万级可训练参数取得与全量微调相当的结果；并非每个配置每个指标都更高。
  • 实践：增量可独立保存和切换，合并到主干后不新增推理分支；这让主模型与专用采样器适配器可以分工。
  • 代价：低秩与目标模块构成表达能力限制；未合并、多适配器混合服务仍有额外计算和管理成本。
  • 开放问题：任务越偏离预训练分布，应该增加 rank、覆盖更多层，还是直接采用全量更新？

低秩增量到底约束了什么

对 \(W_0\in\mathbb R^{d\times k}\)，设 \(A\in\mathbb R^{r\times k}\)、\(B\in\mathbb R^{d\times r}\)。前向计算为：

\[h=W_0x+\frac\alpha r BAx.\]

训练参数从 \(dk\) 变成 \(r(d+k)\)，且 \(\operatorname{rank}(BA)\le r\)。\(r\) 是表达预算，\(\alpha/r\) 控制更新尺度，两者不是同一个超参数。原论文令 \(A\) 随机高斯初始化、\(B=0\)，确保起始模型与预训练模型一致；第一步主要更新 \(B\)，随后两者共同学习。

这不是先训练一个全秩更新再做 SVD 压缩，而是在优化期间始终使用因子化参数。它也不是“所有梯度都低秩”：不同训练步的变化与因子耦合，会使优化路径不同于直接更新 \(W\)。低秩仅限制最终被参数化的矩阵增量。

节省的是哪些成本

冻结主干后，无需为其维护梯度和 Adam 的优化器状态，但反向传播仍需要经过主干来训练较早层的适配器，激活、主干权重与输入长度仍消耗显存。原文 GPT-3 175B 配置报告训练显存从 1.2TB 降至 350GB，不能外推为任意实现都节省同一比例。

只在 query/value 上使用 rank 4 时，作者报告任务检查点约 35MB，而全模型约 350GB。前者是增量：部署仍需要主干，不是 35MB 就能独立运行一个 175B 模型。要消除额外推理分支，可计算 \(W=W_0+\alpha BA/r\)；若要同时为一个 batch 服务多个任务，则合并单一适配器的便利性会下降。

rank 不是唯一的表达预算

固定约 18M 参数预算时，GPT-3 上只适配 \(W_q\)、rank 8 的 WikiSQL 为 70.4；同时适配 \(W_q,W_v\)、各 rank 4 为 73.7；四种注意力矩阵、各 rank 2 也为 73.7。这意味着将预算分配到不同功能模块，可能比只提高单一模块的 rank 更重要。

query/value 的 rank 扫描中，WikiSQL 在 \(r=1,2,4,8,64\) 上为 73.4、73.3、73.7、73.8、73.5，收益并不单调。原文的子空间重合分析支持这些任务的重要更新方向较少，但不证明大范围跨语言迁移、复杂推理或所有层都具有同样的低秩结构。原始实验主要研究注意力权重；后来常见的 MLP 适配不应倒写成原论文已经验证的结论。

为什么 E2S 要把 LoRA 用作采样器

E2S 可以用适配器表示条件采样器，同时用关闭适配器的主干表示学生。好处不仅是省参数，还能明确区分“为了产生适合学生的正确数据而学习的分布”与“最终部署的分布”。但在线阶段一旦更新主干，固定的 LoRA 也会继承主干变化：采样器并未在数学上保持不变，必须重新适配新的目标。

该如何判断你的任务需要多大的适配器

固定总训练参数、数据与 GPU 时间，对比“更高 rank 的少量模块”和“较低 rank 的更多模块”，并检查验证 loss、主任务及保留能力。再记录优化器、激活、主干和 KV cache 的实际显存分项，分别测试合并与未合并服务。这样可以避免用检查点大小替代显存、用参数数量替代吞吐，或把一次局部 rank 消融当成普遍规律。

结论

LoRA 是一种可控的更新参数化，而非低成本能力提升的保证。它最持久的贡献在于把庞大共享主干与较小任务增量分离；表达能力、优化尺度和部署方式仍需要根据任务共同选择。
